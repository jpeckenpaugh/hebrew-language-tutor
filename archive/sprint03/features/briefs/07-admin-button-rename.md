# Brief 07 — Admin Button Rename

## Purpose

Shorten the Admin button label on the Title screen.

## Expected Behavior

1. On the Title screen, the button labeled "Admin Area" is relabeled "Admin".
2. The button's behavior is unchanged.

## Inputs / Outputs

- **Inputs (user):** none (a label change).
- **Outputs (user):** the Title screen showing an "Admin" button.

## User-Visible Behavior

The Title screen shows an "Admin" button instead of "Admin Area". Clicking it
behaves exactly as before.

## Constraints

- Label change only; do not change the button's behavior or styling beyond the
  label text.

## Basic Acceptance Expectations

- The Title screen button reads "Admin".
- Clicking it produces the same behavior as the previous "Admin Area" button.
