# Brief 02 — Remove Footer

## Purpose

Clean up the page by removing the footer line so the page ends after the main
content.

## Expected Behavior

1. The footer text "English / Hebrew Language Tutor — state served by the
   backend API" is removed from the page.
2. The page now ends after the main content; no footer line is rendered.

## Inputs / Outputs

- **Inputs (user):** none (a static page change).
- **Outputs (user):** the page without the footer line.

## User-Visible Behavior

The footer text is no longer visible at the bottom of any screen. The main
content is the last thing the user sees.

## Constraints

- Remove only the footer line; do not change any other page content or layout.

## Basic Acceptance Expectations

- The footer text no longer appears on any screen.
- All other page content and behavior is unchanged.
