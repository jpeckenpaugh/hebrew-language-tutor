# Feature: Catalog Breadcrumb Navigation

- **Sprint:** 03
- **Scope item:** a.)
- **Status:** capability definition

## Capability

Every dynamically-rendered link that points back to the Lesson Catalog works
after the page renders. This covers the "Catalog" breadcrumb on the Lesson
screen and on the Study and results screens, as well as the results screen's
"All Lessons" button — all of which return the user to the Lesson Catalog.

## Scope Notes

- Repairs broken navigation only; no change to catalog behavior itself.
