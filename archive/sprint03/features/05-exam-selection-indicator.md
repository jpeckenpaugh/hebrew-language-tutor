# Feature: Exam Selection Indicator

- **Sprint:** 03
- **Scope item:** e.)
- **Status:** capability definition

## Capability

In Exam mode, after the user selects an answer, the chosen option is shown with
a neutral (e.g. grey/highlighted) style so the user can see their selection was
accepted, without revealing correctness (unlike Quiz mode).

## Scope Notes

- The indicator is neutral; it must not reveal correct/incorrect status in Exam.
