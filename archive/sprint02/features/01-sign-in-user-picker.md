# Feature: Sign-In User Picker

- **Sprint:** 02
- **Scope item:** a.)
- **Status:** capability definition

## Capability

The Title screen provides a dropdown listing existing user accounts so a
returning user can select their name from the list instead of typing it.

## Scope Notes

- Selection alone does not sign the user in; the user still clicks Sign In to
  enter (pick-then-sign-in).
- The list of existing users is populated from the backend (the single in-scope
  backend addition supporting this capability — scope constraint i.).
